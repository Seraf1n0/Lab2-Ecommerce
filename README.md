# Lab2 - Ecommerce

## Pregunta #1: ¿Cómo se adaptaron los componentes de Algolia para que coincidan con la paleta de colores y el sistema de diseño del Proyecto I?

En los filtros de precios se agregó un color distinto para ambas barras y símbolos de dinero, para diferenciar el aumento o la disminución del rango. La paginación también tuvo cambios en cuanto al tamaño y color de cada número de página, para que fuera distinguible para el usuario. La barra de búsqueda se hizo más ancha conforme a la pantalla del dispositivo utilizado.

En cuanto a colores, se mantuvieron muy neutros: el fondo se conservó blanco y los demás componentes o tarjetas solo presentan sombras con borde en gris o morado. La tipografía se mantuvo igual, exceptuando que se usaron colores entre morado, blanco y negro para dar mejor contraste.

En general, se reutilizaron todos los componentes del Proyecto I, ya que esto ahorraba trabajo y mantenía el diseño de forma limpia y consistente entre ambos entregables.

## Pregunta #2: Justificar la ubicación de los filtros, la barra de búsqueda y la paginación. ¿Por qué esta disposición facilita el proceso de compra del usuario?

Los filtros se encuentran en la parte superior izquierda, por debajo de la barra de búsqueda. Se dejaron en esta posición puesto que los usuarios están acostumbrados a observar la página desde la esquina superior izquierda y descender en forma diagonal hasta la esquina inferior derecha, por lo que esta ubicación facilita su localización tanto en dispositivos grandes como pequeños.

De igual manera, la barra de búsqueda se coloca en la parte superior, ya que facilita la búsqueda constante de productos y no presenta ningún reto para encontrarla.

Por último, la paginación es un pequeño filtro en la esquina superior derecha, por debajo de la barra de búsqueda, que permite mostrar 16, 32 o 64 artículos por página, dependiendo de cuántos resultados desee ver el usuario.

Todo lo mencionado anteriormente reduce la fricción del proceso de compra, ya que el usuario no tiene que buscar los controles: los encuentra donde su ojo ya espera encontrarlos, acelerando su recorrido de búsqueda a compra.

## Pregunta #3: Explicar brevemente qué sucede visualmente en la interfaz si una búsqueda no arroja ningún resultado (Empty State)

Si no se encuentra ningún resultado, a nivel visual se muestra un mensaje en la interfaz explicando que no se han encontrado resultados con la palabra buscada, acompañado de un ícono de una X para reforzar visualmente el mensaje. Así se le permite al cliente comprender que el producto no existe en el sistema o que no coincide con ningún resultado disponible.
